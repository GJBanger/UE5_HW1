\# Домашнее задание №1: Основы механики



\## Что реализовано:

\- C++ класс AHWCharacter, наследованный от ACharacter.

\- Настроен Enhanced Input (Спринт и Взаимодействие).

\- Спринт изменяет скорость и переключает анимацию через State Machine.

\- Система выносливости (Stamina): тратится при беге, восстанавливается при ходьбе. При 0 бег невозможен.

\- Делегат OnInteract, вызывается по нажатию клавиши.



\## Управление:

\- \*\*W, A, S, D\*\* — Передвижение

\- \*\*Пробел\*\* — Прыжок

\- \*\*Left Shift\*\* — Спринт (при наличии выносливости)

\- \*\*E\*\* — Взаимодействие (вывод текста, прикольного. Надеюсь не снизят баллы)
