\# Домашнее задание №1: Основы механики



\## Что реализовано:

\- C++ класс AHWCharacter, наследованный от ACharacter.

\- Настроен Enhanced Input (Спринт и Взаимодействие).

\- Спринт изменяет скорость и переключает анимацию через State Machine.

\- Система выносливости (Stamina): тратится при беге, восстанавливается при ходьбе. При 0 бег невозможен.

\- Делегат OnInteract, вызывается по нажатию клавиши.



\## Управление:

\- \*\*W, A, S, D\*\* — Передвижение

\- \*\*Пробел\*\* — Прыжок

\- \*\*Left Shift\*\* — Спринт (при наличии выносливости)

\- \*\*E\*\* — Взаимодействие (вывод текста, прикольного. Надеюсь не снизят баллы)


# Домашнее задание №2: Behavior Trees и PCG

Продолжение первого домашнего задания.

## Что реализовано

- Генерация препятствий на карте с помощью PCG.
- NavMesh для передвижения охранника и обхода препятствий.
- C++ классы персонажа и контроллера ИИ.
- Blackboard и Behavior Tree для управления охранником.
- Анимации ходьбы, бега и стояния на месте.

## Поведение охранника

- Patrol — охранник ходит по случайным точкам вокруг места спавна.
- Chase — если охранник замечает игрока, то начинает его преследовать.
- Investigate — если охранник теряет игрока или слышит шум, то идёт проверять его последнее известное местоположение или место шума.

После проверки охранник возвращается к патрулированию.

## Дополнительное задание на 9–10 баллов

Реализовал реакцию охранника на шум от спринта игрока. Если пробежать рядом с охранником за пределами его зоны обнаружения, он услышит шум и пойдёт проверять это место. При обычной ходьбе такой реакции нет.

Для реализации поведения используются собственные узлы Behavior Tree на C++.
